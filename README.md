# Практическая работа №3. Bootstrap 5, Bootstrap JavaScript и базовый JavaScript

Адаптивная административная панель статуса проекта на Bootstrap 5. Показатели, операции и уведомления загружаются из JSON-файлов в папке `data`.

## Технологии

- HTML5
- Bootstrap 5.3 (CSS и `bootstrap.bundle.min.js` с CDN)
- JavaScript

## Требования

- Современный браузер (Chrome, Edge, Firefox)
- Подключение к интернету (Bootstrap подключается с CDN)
- Локальный сервер: расширение Live Server для VS Code или Node.js

## Запуск

Страницу нужно открывать через локальный сервер. Если открыть `index.html` двойным кликом, браузер запретит `fetch` читать JSON-файлы, и на странице появится сообщение об ошибке.

Вариант 1 — VS Code:

1. Установить расширение **Live Server**.
2. Открыть папку проекта в VS Code.
3. Нажать правой кнопкой на `index.html` → **Open with Live Server**.

Вариант 2 — Node.js:

```
npx serve .
```

После запуска открыть адрес, который покажет команда (обычно `http://localhost:3000`).

## Структура проекта

```
index.html          разметка страницы
css/custom.css      собственные стили
js/app.js           собственный JavaScript
data/               dashboard.json, notifications.json
images/             avatar.svg, chart.svg
dataset/            исходный dataset задания
```

## Использованные файлы dataset

- `dashboard.json`:
  - `metrics` — 4 карточки показателей;
  - `rows` — таблица последних операций.
- `notifications.json`:
  - список уведомлений в offcanvas;
  - текст toast: `success` после сохранения, `warning` при ошибке в форме.
- `avatar.svg` — аватар пользователя в navbar.
- `chart.svg` — изображение в карточке «Статистика».

## Используемые компоненты Bootstrap

- Grid: `container`, `row`, `col-12 col-sm-6 col-lg-3`, `col-lg-8`, `col-lg-4`
- Navbar с collapse (меню сворачивается на узком экране)
- Card
- Table в контейнере `table-responsive`
- Badge
- Alert
- Form: `form-control`, `form-select`, `form-label`, `form-text`, `invalid-feedback`
- Modal
- Offcanvas
- Toast
- Utility-классы для отступов, выравнивания и цвета

## Что делает Bootstrap JavaScript

- раскрывает и сворачивает меню navbar (collapse) через `data-bs-toggle="collapse"`;
- открывает modal через `data-bs-toggle="modal"` и закрывает его через `data-bs-dismiss="modal"`;
- открывает и закрывает offcanvas через `data-bs-toggle="offcanvas"`;
- показывает и скрывает toast.

## Что делает app.js

- загружает `dashboard.json` и `notifications.json` через `fetch`;
- выводит карточки показателей, таблицу операций и список уведомлений;
- обработчик `submit` формы: проверяет поле, добавляет операцию в таблицу, закрывает modal и показывает toast;
- обработчик `input` поля «Название операции»: проверяет поле при вводе и ставит класс `is-invalid` или `is-valid`;
- обработчик `click` кнопки «Только новые»: фильтрует таблицу и меняет текст кнопки на «Показать все» и обратно;
- обновляет счётчик операций рядом с заголовком таблицы;
- получает компоненты программно: `bootstrap.Toast.getOrCreateInstance` и `bootstrap.Modal.getOrCreateInstance`.

## Ошибочные и пустые состояния

- Если JSON-файлы не загрузились, показывается красный блок `alert-danger`.
- Если название операции короче 3 символов, поле подсвечивается красным, под ним показывается текст ошибки и появляется toast с предупреждением.
- Если после фильтрации операций нет, в таблице выводится строка «Операций нет».

## Что изменилось после шага 5

Добавлена таблица последних операций из `dashboard.json`. Таблица находится в `table-responsive`, поэтому на ширине 375px прокручивается внутри карточки, а не вся страница.

## Проверка

1. Запустить проект по инструкции выше.
2. Открыть DevTools → Console: ошибок нет.
3. Нажать «Добавить операцию», оставить поле пустым и нажать «Сохранить» — поле красное, toast с предупреждением.
4. Ввести название и нажать «Сохранить» — строка добавлена, счётчик увеличился, toast «Изменения сохранены».
5. Нажать «Только новые» — в таблице остаются операции со статусом «Новая», текст кнопки меняется.
6. Нажать «Уведомления» — справа открывается offcanvas.
7. В Responsive Mode проверить ширины 375 и 1440px: на 375px меню сворачивается в кнопку, карточки показателей встают в одну колонку.
